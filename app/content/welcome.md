# Welcome

This is a sample markdown page served via React Router SSR and rendered by CloudFront.

## Features

- GitHub Flavored Markdown via `remark-gfm`
- Tables, strikethrough, task lists, and more
- Fully server-side rendered in Lambda

## Get started
For markdown content on react router use
```npx create-react-router@latest my-web-app --template DeepjyotiDeb/aws-lambda-support#md```
